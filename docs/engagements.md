# Engagement models

Engagements begin with a review of your infrastructure, business priorities, and operational constraints. This discovery work establishes the project scope and deliverables.

- Assessment and advisory. Assess the environment, document findings, and recommend next steps.
- Project delivery. Design and implement infrastructure changes, including migration and documentation.
- Ongoing consulting. Provide architecture advice, troubleshoot complex issues, and plan infrastructure changes.

## Automation engagement examples

| Engagement | Typical deliverable |
|---|---|
| Datacenter automation assessment | Opportunity analysis and prioritized automation roadmap |
| Hyper-V fabric deployment automation | Scripts and configuration files for repeatable Hyper-V host and cluster deployment |
| Automated server build framework | Standardized physical and virtual server provisioning |
| Image factory | Automated image build, validation, and publishing pipeline |
| Workload deployment framework | Repeatable application and infrastructure workload deployment |
| Azure infrastructure deployment framework | Configuration-driven Azure provisioning and deployment |
| AVD deployment & lifecycle automation | Automated host pools, images, session hosts, and maintenance |
| Infrastructure configuration compliance | Automated configuration validation and drift remediation |
| PowerShell automation platform development | A shared system for coordinating deployments, tracking progress, and recovering from failures |
| Existing PowerShell code modernization | Refactored, tested, secured, and documented automation code |

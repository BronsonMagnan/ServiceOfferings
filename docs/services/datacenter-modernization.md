# Datacenter modernization

Assess VMware environments, plan migrations to Hyper-V and System Center, and upgrade the compute, storage, and networking infrastructure that supports hosted applications.

- VMware inventory, health assessment, and workload dependency analysis
- VMware-to-Hyper-V migration planning, VM conversion, and workload migration
- Hyper-V and Windows Server failover cluster design and deployment
- Azure Stack HCI architecture and deployment
- Storage Spaces Direct cluster design and implementation
- System Center Virtual Machine Manager (SCVMM) architecture and deployment
- Cluster Shared Volumes and shared storage design
- Hyper-V networking and virtual switch configuration
- Microsoft SDN fabric design and deployment
- NVIDIA GPU passthrough to Hyper-V virtual machines using Discrete Device Assignment
- SAN, NAS, iSCSI, and Fibre Channel storage architecture
- System Center Operations Manager monitoring and SCVMM integration
- System Center Data Protection Manager backup integration
- Compute, storage, and network capacity planning
- Server hardware lifecycle and replacement planning
- Lenovo xServer deployment and configuration
- Phased host upgrades and workload migration
- Datacenter consolidation
- Legacy VMware infrastructure decommissioning

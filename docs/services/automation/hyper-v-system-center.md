- Hyper-V fabric discovery and configuration automation
- Hyper-V host provisioning and configuration
- Hyper-V virtual switch and network adapter configuration
- Storage Spaces Direct and shared storage configuration workflows
- Windows Server Failover Cluster deployment automation
- Cluster node validation and configuration
- Cluster Shared Volume provisioning and management
- System Center Virtual Machine Manager (SCVMM) integration
- SCVMM host group, cloud, and fabric resource automation
- SCVMM logical network and IP pool deployment
- SCVMM host profile and template automation
- SCVMM service and VM template deployment
- SCVMM library server and resource management
- Hyper-V virtual machine provisioning
- VM configuration, resizing, and lifecycle management
- Virtual machine live migration and placement orchestration
- Host evacuation and maintenance-mode automation
- Cluster capacity and placement reporting
- Fabric configuration consistency validation
- Automated VMware workload migration workflows
- Post-migration workload validation
- System Center Operations Manager integration
- Fabric monitoring, alerting, and operational reporting
- Host and cluster decommissioning automation

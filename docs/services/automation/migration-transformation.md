# Migration & transformation automation

Part of [PowerShell automation & infrastructure engineering](../powershell-automation.html).

## Capabilities

- VMware-to-Hyper-V migration orchestration
- Source infrastructure discovery and workload inventory
- VM compatibility and prerequisite assessment automation
- VM migration scheduling and tracking
- Workload dependency verification
- Target VM provisioning and configuration
- Storage and data migration automation
- Server role and application configuration migration
- Migration cutover and post-cutover validation
- Automated infrastructure comparison and reconciliation
- Azure subscription and resource migration orchestration
- On-premises-to-Azure server migration support
- Active Directory domain and forest migration workflows
- Fileserver and permissions migration
- Application hosting environment migration
- Backup and recovery infrastructure transition
- Automated decommissioning and residual resource cleanup
- Migration evidence collection and reporting

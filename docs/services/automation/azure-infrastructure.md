- Azure management group and resource hierarchy automation
- Azure resource tagging and governance

- Azure virtual network and subnet provisioning
- Network security group and application security group configuration
- Azure Firewall and firewall policy deployment
- VPN Gateway and site-to-site connectivity provisioning
- Virtual network peering and routing automation
- Private Endpoint and Private DNS configuration
- Azure Load Balancer and Application Gateway provisioning

- Virtual machine disk, NIC, and extension management
- Azure availability zone and availability set deployment
- Managed identity and service principal provisioning
- Azure Key Vault deployment and secret management
- Azure Storage account and Azure Files provisioning
- Storage access control and private connectivity configuration
- Azure Backup and Recovery Services vault deployment
- Azure Site Recovery infrastructure provisioning
- Azure Monitor and Log Analytics deployment
- Data Collection Rule and monitoring agent configuration
- Azure Arc onboarding and configuration
- Microsoft Defender for Cloud integration
- Azure Update Manager deployment
- Azure Compute Gallery management
- Azure resource migration and redeployment automation
- Multi-subscription and multi-region infrastructure orchestration
- ARM and Bicep template integration with PowerShell
- Post-deployment configuration and validation
- Resource inventory, governance, and compliance reporting
- Automated resource retirement and cleanup

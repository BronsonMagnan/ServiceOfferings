# Service offering catalog

A catalog of IT infrastructure architecture, engineering, and consulting services for organizations hosting applications on Microsoft platforms.

The catalog describes service scope and capabilities across datacenter modernization, Microsoft server infrastructure, application hosting, Azure, networking, identity security, PowerShell automation, backup and recovery, and IT operations. It also covers infrastructure advisory, technical debt reduction, and Microsoft service-provider licensing strategy.

## Service focus

- VMware-to-Hyper-V migration and System Center infrastructure
- Windows Server, Active Directory, PKI, file services, and clustering
- Remote Desktop Services, Azure Virtual Desktop, application packaging, and FSLogix
- Identity security and privileged administration
- PowerShell automation for deployment, configuration, and maintenance
- Infrastructure availability, performance, monitoring, and recovery

Engagements include assessments, architecture and implementation projects, and ongoing technical consulting. Each service page describes the work available within that area.

The website uses Markdown source files in `docs/`, which Jekyll converts into a static site for GitHub Pages.
